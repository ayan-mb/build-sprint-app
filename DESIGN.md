# Milestone 1 diagnostic screen

Mode: operate. A single SEO manager enters one borrower question and one relevant NBFC web page, then inspects answers, citations and page evidence.

Use a practical comparison worksheet: inputs above the results; Perplexity and ChatGPT side by side on desktop and stacked on narrow screens; quoted cited evidence beside the NBFC evidence. No landing page, navigation to future features, generated article, or share-of-voice dashboard.

Palette: ink #173c55, background #edf2f5, paper #ffffff, action #146477, supporting text #526776, warning text #654911 on #fff0cc. Avenir Next with Avenir and Segoe UI fallbacks. Left aligned text, 1160px maximum workspace, body text 16px, clear keyboard outlines, 48px action button, no required motion. Status includes words as well as colour.

Show provider keys as configured or missing, never their values. Keep missing citations, unavailable pages and shortened captures visible. Only label a finding missing on the captured page, with an exact source quotation and working source link. Clearly distinguish topic checks from AI comparison suggestions. Competitor rates are evidence to review, not NBFC terms to reuse.

Verification: source and result components are checked with actual HTML-rendering tests. Browser visual inspection remains blocked by unavailable browser tooling and pending desktop Accessibility / Screen Recording permission; do not label this as browser-verified.
